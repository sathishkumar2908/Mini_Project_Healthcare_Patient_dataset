Healthcare Revenue Analytics

## Project Overview

This project focuses on analyzing healthcare patient and hospital billing data using Microsoft Excel and Power BI. The project covers data cleaning, data transformation, descriptive analysis, Pivot Table analysis, interactive reporting, and dashboard creation.

The main objective is to understand hospital revenue, patient volume, department performance, insurance contribution, admission patterns, and operational performance and present meaningful business insights through interactive visualizations.

## Problem Statement

The project aims to analyze healthcare revenue and patient performance across different hospitals, departments, insurance types, and admission categories. It also focuses on understanding patient and operational behavior through admission type, length of stay, billing, and other healthcare-related metrics.

The analysis helps identify high-performing hospitals and departments, understand revenue trends and insurance contribution, and provides a clear view of overall healthcare business performance through Excel analysis and an interactive Power BI dashboard.

## Data Source

**Source:** Synthetic Healthcare Patient Dataset  
**Domain:** Healthcare Analytics and Hospital Revenue  
**Records:** 1,000 patient records

## Data Pre-processing

### Excel Data Pre-processing

Removed duplicate records and handled missing values where required. Standardized admission and discharge date formats and validated numerical fields.

Created calculated fields for:

- Age Groups
- Admission Month
- Length of Stay analysis

Created a descriptive summary of revenue, patients, average billing, and length of stay.

Created Pivot Tables for:

- Hospital Revenue Analysis
- Department Billing Analysis
- Monthly Revenue Trend
- Insurance Analysis
- Length of Stay Analysis
- Hospital Revenue Contribution

### Power BI Data Pre-processing

Imported the cleaned healthcare dataset into Power BI and transformed the data using Power Query.

The preprocessing included:

- Checking and modifying data types
- Standardizing date fields
- Removing unnecessary blank rows
- Validating numerical fields
- Checking column quality
- Preparing the dataset for analysis

Created DAX measures for:

- Total Revenue
- Patient Count
- Average Bill
- Average Length of Stay
- Revenue Contribution %

## Power BI Reports

The analysis was organized into different areas based on healthcare revenue and operational performance.

**1. Healthcare Revenue Overview**

This report provides an overall view of revenue and patient performance using KPI cards, monthly revenue trends, hospital revenue, department revenue, and insurance analysis.

**2. Hospital and Department Performance**

This report focuses on hospital and department-level performance to understand variations in revenue, patient volume, and operational metrics.

**3. Patient and Insurance Analysis**

This report analyzes admission types, insurance categories, patient volume, average billing, and other patient-related patterns.
